# Bildschirmaufnahmen

Hier liegen Aufnahmen vom Telefon, mit denen ein Fehler gezeigt wird.

Bewusst **nicht** in `myprosole_app/design/`: dieser Ordner wird als Ganzes
veroeffentlicht. Eine Aufnahme des eigenen Telefons hat auf einer oeffentlichen
Adresse nichts zu suchen.

Der Inhalt wird nicht in Git aufgenommen (siehe `.gitignore`) – Aufnahmen
zeigen oft mehr als beabsichtigt: Benachrichtigungen, Namen, Uhrzeiten.
