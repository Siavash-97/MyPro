# Assets

`foot_template.png` is a fixed PNG template used by the pressure-map canvas.
It is derived from the lower insole in the Wikimedia Commons file
`Textile and latex foam inner soles - upper side.jpg` by W.carter, published as
CC0 1.0 Universal Public Domain Dedication:
https://commons.wikimedia.org/wiki/File:Textile_and_latex_foam_inner_soles_-_upper_side.jpg

`foot_mask.png` is the black/white mask derived from the template image and is
used only to clip the transparent heatmap overlay inside the insole shape.
